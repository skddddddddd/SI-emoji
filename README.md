# 祀的表情包

《明日方舟：终末地》祀的动态表情包，共 72 张 GIF，适配 AstrBot `meme_manager`。

## 安装

在 AstrBot 的「表情包管理器」→「资源广场」中，使用仓库地址安装：

```text
https://github.com/skddddddddd/SI-emoji
```

## 目录结构

```text
manifest.json
memes/daily/*.gif
previews/*.png|jpg
```
